# LEVEL UP — Gaming Community Website

A responsive gaming community and game showcase website created using **HTML5 and CSS3 only**.

## Folder Structure

```text
LEVEL-UP-Gaming-Website/
│
├── index.html
├── about.html
├── gallery.html
│
├── css/
│   └── style.css
│
├── images/
│   └── image-files
│
└── README.md
```

## Pages

- `index.html` — Homepage, featured games, game library, community preview, and join section.
- `about.html` — Information about the LEVEL UP gaming community.
- `gallery.html` — Game showcase gallery.
- `css/style.css` — Shared website styling and responsive layout.
- `images/` — Folder for your own image files. The current design also uses online image URLs in the CSS.

## How to Open

1. Extract the ZIP file.
2. Open the `LEVEL-UP-Gaming-Website` folder.
3. Double-click `index.html` to view the website in a browser.

## Technologies

- HTML5
- CSS3

No JavaScript or backend is used. The community chat is a visual sample and does not send live messages.

## Publishing with GitHub Pages

1. Create a GitHub repository.
2. Upload all files and folders while keeping the same structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
